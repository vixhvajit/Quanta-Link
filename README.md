# Quanta-Link

[![License](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

A lightweight, quantum-encrypted link protocol for drones, covering command and
telemetry between the ground station and the aircraft.

## Status

Early stage. The protocol is not specified and nothing is implemented yet.
